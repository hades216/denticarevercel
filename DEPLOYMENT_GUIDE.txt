================================================================================
                    IONOS STARTER PLAN DEPLOYMENT GUIDE
================================================================================

YOUR WEBSITE IS READY FOR DEPLOYMENT! ✅

================================================================================
STEP 1: BUILD YOUR WEBSITE
================================================================================

Open terminal/command prompt and run:

  npm install
  npm run build

This creates a "dist" folder with all files ready to upload.

Expected output:
  ✓ dist/index.html
  ✓ dist/assets/main.*.js
  ✓ dist/assets/main.*.css
  ✓ dist/assets/ (images and other files)

================================================================================
STEP 2: UPLOAD TO IONOS VIA FTP
================================================================================

1. Open FTP Client (FileZilla, WinSCP, etc.)

2. Connect to IONOS:
   - Host: [Your FTP server from IONOS control panel]
   - Username: [Your FTP username]
   - Password: [Your FTP password]
   - Port: 21 (or 22 for SFTP)

3. Navigate to: public_html (or www folder)

4. IMPORTANT - Enable "Show hidden files":
   - FileZilla: View → Show hidden files
   - WinSCP: View → Show hidden files

5. Upload all files from "dist" folder to public_html

6. VERIFY .htaccess IS UPLOADED:
   - Look for ".htaccess" file in root
   - If not visible, enable "Show hidden files"
   - If missing, upload from "public/.htaccess"

7. Set file permissions:
   - Files: 644
   - Directories: 755
   - .htaccess: 644

================================================================================
STEP 3: TEST YOUR WEBSITE
================================================================================

1. Visit your domain in browser

2. Test these things:
   ✓ Homepage loads
   ✓ Navigation works (click links)
   ✓ Images display correctly
   ✓ Styles are applied (colors, fonts)
   ✓ Forms work (if any)
   ✓ Mobile view works

3. If issues occur:
   - Clear browser cache (Ctrl+Shift+Delete)
   - Hard refresh (Ctrl+F5)
   - Check browser console (F12)
   - See TROUBLESHOOTING.md

================================================================================
CRITICAL FILES
================================================================================

MUST UPLOAD:
  ✓ dist/index.html
  ✓ dist/assets/ (all files)
  ✓ public/.htaccess (HIDDEN FILE - enable "Show hidden files"!)

MUST NOT UPLOAD:
  ✗ .env file
  ✗ node_modules folder
  ✗ src folder
  ✗ package.json

================================================================================
WHAT IF PAGES SHOW 404 ERRORS?
================================================================================

This means .htaccess is not working. Fix it:

1. Verify .htaccess is uploaded:
   - Enable "Show hidden files" in FTP client
   - Check it exists in root directory

2. Check file permissions:
   - Right-click .htaccess → Properties
   - Set to 644

3. Contact IONOS support:
   - Ask them to enable "mod_rewrite" module
   - Provide them this error

4. Verify .htaccess content:
   - Should start with: <IfModule mod_rewrite.c>
   - Should contain: RewriteEngine On

================================================================================
WHAT IF STYLES/IMAGES DON'T LOAD?
================================================================================

1. Clear browser cache:
   - Ctrl+Shift+Delete
   - Select "All time"
   - Check "Cookies and other site data"
   - Check "Cached images and files"
   - Click "Clear data"

2. Hard refresh:
   - Ctrl+F5 (or Cmd+Shift+R on Mac)

3. Check browser console (F12):
   - Look for red error messages
   - Check Network tab for 404s

4. Verify files uploaded:
   - Connect to FTP
   - Check dist/assets/ folder exists
   - Verify all files are there

================================================================================
ENVIRONMENT VARIABLES (If using Supabase)
================================================================================

1. Create .env file locally:
   VITE_SUPABASE_URL=your_url
   VITE_SUPABASE_ANON_KEY=your_key

2. Run build:
   npm run build

3. Upload dist/ folder

4. NEVER upload .env file to server!
